## Color pipeline (what makes the rice “live”)

1. Wallpaper changes (selector, random, or `next-wallpaper`).
2. Noctalia regenerates Material You colors (`muted` + `useWallpaperColors`).
3. Built-in templates recolor: **Kitty, Niri, Starship, Zen, btop, cava, …**
4. User templates recolor: **Vesktop (system24), fastfetch, aesthetic.env, optional VS Code**.
5. Hook `fix-zen-noctalia-theme` keeps Zen’s `userChrome` import chain clean (no double CSS).

## Generated at runtime (safe to overwrite)

| Path | Source |
|------|--------|
| `~/.config/niri/noctalia.kdl` | Noctalia `niri` template |
| `~/.config/kitty/themes/noctalia.conf` | Noctalia `kitty` template |
| `~/.config/vesktop/themes/system24.theme.css` | `templates/discord.css` |
| `~/.config/fastfetch/config.jsonc` | `templates/fastfetch.jsonc` |
| `~/.config/aesthetic/noctalia.env` | `templates/aesthetic.env` |
| Starship `[palettes.noctalia]` block | `templates/starship.toml` + apply script |
| Zen cache under `~/.cache/noctalia/zen-browser/` | Noctalia `zenBrowser` |

Samples of those files ship in the repo so a fresh clone still looks coherent before the first wallpaper pick.
